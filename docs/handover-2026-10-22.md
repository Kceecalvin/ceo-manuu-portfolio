## Editing and operation

There is no owner CMS or administrator dashboard. Content changes are made in
source, reviewed, built and deployed. `src/lib/portfolio.ts` holds founder details,
venture areas and the site URL. `src/lib/businesses.ts` holds all ten businesses,
services and brand copy. `src/lib/collaborations.ts` holds enquiry paths.

Update source content, inspect it on mobile and desktop, run `npm test`,
`npm run lint` and `npm run build`, then review the diff before publishing.
Refresh `public/images/businesses/` screenshots when a business hero changes.
SeroTix screenshots in `public/images` are static product previews from September;
the ticketing application is separate and is not deployed by this repository.

Customer contact details are not stored by this portfolio. With direct delivery
configured, staff receive a notification and reply from the chosen mailbox.
Without credentials, `/contact` prepares a draft for the visitor to send.
The published support page has unavailable, email-draft and direct-send modes.
It is not a durable ticketing/help-desk database. Customer acknowledgement templates
exist but are not wired to automatic delivery. See the three email setup documents.

## Domain and mailbox work

DNS currently uses `ns1.cloudoon.com`, `ns2.cloudoon.net`, `ns3.cloudoon.org`.
The apex A record is `216.198.79.1`. Preserve the working apex website record.
`ceomanuu.com` has no MX/TXT answers at this audit, and `www` does not resolve.
Do not invent the Vercel CNAME target: obtain it in the owning project's Domains
settings. Adding a DNS record alone does not create an HTTPS redirect or register
the hostname with the hosting project. Verify HTTPS and preservation of paths after
configuring the redirect (for example `/ventures` should remain `/ventures`).

Mailboxes proposed in previous work (`hello@ceomanuu.com`, `support@ceomanuu.com`)
are not provisioned by this code. Use the selected mail host's exact regional
MX/SPF/DKIM records, preserving the website records and a single SPF policy.
The owner must complete account verification and confirm inbox receipt/replies.
SeroTix's Brevo sender is a separate configuration; it does not activate this site.

## Reproducible local setup and release

Use Node 22+ (validated with Node 24.20.0) and the included package-lock.json.

```sh
npm ci
npm test
npm run lint
npm run build
npm start -- --hostname 127.0.0.1 --port 3030
```

For development use `npm run dev -- --hostname 127.0.0.1 --port 3030`.
Do not expose the development server as the production website.

GitHub main automatically deploys to the existing Vercel project under
`kceecalvins-projects`; the release above verified that integration. Confirm
the project, Node runtime and environment variables before future configuration
changes. Commit reviewed source to main. After a successful build, check all
business routes, metadata, contact mode, support mode and mobile navigation.
Provider acceptance of an email is not confirmation of final inbox delivery.

A deployment rollback restores code only; environment variables and DNS need
separate records. Retain an export/screenshot of configuration and a known-good
patched release. An older release can restore an outage but may reintroduce known
dependency issues; do not leave it as the steady state. Domain/mail data belong
in the owner's account and password manager, not in the shareable source archive.
